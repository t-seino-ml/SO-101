## 目的

フォロワー機の視点と作業領域を撮影し、後段のデータ記録・学習・推論に供給できる状態にします。

## 決めること

- **台数と配置** — 手先カメラ（グリッパ搭載）と俯瞰カメラの 2 台構成が一般的です。片方だけでも学習は可能ですが、遮蔽への強さが変わります
- **解像度とフレームレート** — 学習時は 224×224 前後に縮小するのが通例です。記録時の解像度を上げすぎるとディスクと帯域を圧迫します
- **同期方法** — 制御ループは 120 Hz で回っています。カメラは 30 fps 程度なので、制御ループをカメラ取得でブロックしない構造が必要です

## LeRobot 側の既存機能

`lerobot-find-cameras` でカメラの列挙とインデックス確認ができます。自前で列挙処理を書く前にこちらを使ってください。

```bash
uv run python -c "from lerobot.cameras.opencv.configuration_opencv import OpenCVCameraConfig; print(OpenCVCameraConfig)"
```

ロボット設定に `cameras` フィールドがあり、`OpenCVCameraConfig` または `RealSenseCameraConfig` を渡す形になっています。テレオペやデータ記録のコマンドにそのまま乗ります。

## 想定する実装範囲（`src/so101/camera/`）

- カメラの列挙と、**個体を安定して識別する仕組み**。Windows はデバイスインデックスを付け替えるため、`hardware/ports.py` がシリアルポートに対して行っているのと同じ発想が必要です
- 固定解像度・固定フレームレートでの取得
- `dataset` への記録用フレーム供給と、`policy` への推論用フレーム供給
